# VentureX Aventura — redesign (conceito)

Site estático (HTML + CSS + JS, sem dependências). Abra `index.html` no navegador.

Visual: preto + laranja, inspirado em sites de estúdio de landing page.
Animações: título que sobe, palavra que gira, sol com parallax, faixa rolando, texto que acende ao rolar,
contadores, cards 3D, botões magnéticos, linha do tempo horizontal, preços que trocam mensal/anual.

## Antes de publicar, trocar
- Endereço e telefone (marcados no rodapé do formulário)
- Preços (são exemplos)
- Números da seção de estatísticas
- Fotos reais do espaço nos cards (hoje são gradientes com etiqueta "Photo: ...")
- Depoimento real de membro
- Formulário: ligar a um serviço real (hoje só mostra a mensagem de obrigado)
